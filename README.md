# 担当エリア可視化ツール

「ID,郵便番号,担当者」の3列のCSVを読み込み、郵便番号ごとに地図へ円を描いて、
担当者ごとにどのエリアに何人を抱えているかを見えるようにするツールです。

- 対象エリア：東京都・埼玉県・神奈川県・千葉県
- 地図：Leaflet ＋ OpenStreetMap
- **CSVはブラウザの中だけで処理し、どこにも送信しません**（サーバーへのアップロードはありません）

公開URL：https://tomoki-ogawa.github.io/area-map/

---

## 使い方

1. 公開URLをパソコンかスマホのブラウザで開きます。
   最初は架空のダミーデータ（立川市周辺）が表示されます。
2. 「CSVを選ぶ」を押して、手元のCSVファイルを選びます。
3. 地図と表が、選んだCSVの内容に切り替わります。

### 画面の見方

| 場所 | 内容 |
|---|---|
| 地図の円 | 1つの円＝1つの郵便番号。**円の大きさ＝人数**、**円の中の色分け＝担当者の内訳**、中の数字＝人数 |
| 担当者ボタン | 「全員」または担当者名を押すと、その担当者の分だけに絞り込みます（その担当者がいない郵便番号は灰色の小さな点） |
| 円をタップ | その郵便番号の担当者ごとの人数（内訳）が吹き出しと地図の下に出ます |
| 「全体を表示」 | 全部の円が入るように地図を戻します |
| 担当者ごとのまとめ | 担当者ごとの人数・全体に占める割合・エリア数・人数の多い上位3エリア |
| 郵便番号×担当者の表 | 郵便番号ごとの人数の一覧。行をタップすると地図がその場所に移動します |
| 「ダミーに戻す」 | 読み込んだCSVを画面から消して、ダミーデータに戻します |

地図を拡大すると、円の下に町名が表示されます。

### CSVの形式

```csv
ID,郵便番号,担当者
U1001,190-0001,佐藤
U1002,1900002,鈴木
U1003,１９０－０００３,高橋
```

- 1列目：ID（利用者番号など。画面の「位置不明」一覧に出るだけで、名前などは不要です）
- 2列目：郵便番号
- 3列目：担当者名
- 1行目の見出しはあってもなくても大丈夫です。
- 文字コードは **UTF-8** と **Shift_JIS**（Excelで「CSV（コンマ区切り）」保存したもの）の両方に対応しています。
- 郵便番号は `1900001`・`190-0001`・`１９０－０００１`（全角）・`〒190-0001` のどれでも読めます。

### 「位置不明」について

次の場合は地図に出せないため「位置不明」として、件数と例を画面上部に表示します
（「位置不明の一覧を見る」で全件を確認できます）。

- 郵便番号が7桁の数字として読めない（例：桁が足りない、空欄）
- 対応表にない郵便番号（対象の4都県以外、事業所の個別郵便番号、新設されたばかりの番号など）

### 円の位置の精度について

円の位置は「その郵便番号に含まれる町丁目の中心点の平均」です。番地レベルの正確な位置ではありません。
「以下に掲載がない場合」の番号など、町域が決まらない郵便番号は、市区町村の代表点（市区町村内の全町丁目の平均）に置いています。
その場合は、円をタップしたときの内訳に注記が出ます。

### 個人情報の扱い

- CSVはブラウザの中で読み込むだけで、外部へは送信しません。ページを閉じると消えます。
- 外部との通信は、地図の画像（OpenStreetMapのタイル）と地図ライブラリ（Leaflet）の取得だけです。
  地図画像の取得では「どのあたりの地図を表示しているか」がOpenStreetMapのサーバーに伝わりますが、CSVの中身は含まれません。
- このリポジトリには利用者データ（`*.csv` など）をコミットしない設定（`.gitignore`）にしています。
  動作確認には架空のダミーデータだけを使っています。

## 手元で動かす

`index.html` をダブルクリックで開くと、ブラウザの制限で対応表（`data/zip_coords.json`）を読み込めません。
手元で試すときは、このフォルダで簡易サーバーを起動してから開いてください（Python が必要です）。

```powershell
python -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。

## 対応表の作り直し（毎年の更新手順）

郵便番号→座標の対応表 `data/zip_coords.json` は、次の2つの公開データから作っています。

| データ | 提供元 | 使っているもの |
|---|---|---|
| 郵便番号データ（KEN_ALL.CSV） | 日本郵便 | 「読み仮名データの促音・拗音を小書きで表記するもの」全国一括 |
| 位置参照情報（大字・町丁目レベル） | 国土交通省 | 埼玉・千葉・東京・神奈川の4都県分 |

### 手順

Python 3.8以上があれば、追加のインストールは不要です。このフォルダで次を実行します。

```powershell
python tools/build_zip_coords.py
```

スクリプトが自動で次のことを行います。

1. 日本郵便のサイトから最新の `ken_all.zip` をダウンロード
2. 国土交通省のサイトから、位置参照情報（大字・町丁目レベル）の**最新版を自動で探して**4都県分をダウンロード
3. 突き合わせて `data/zip_coords.json` を作り直す
4. 照合できなかった郵便番号の一覧を `tools/report/unmatched.md`（と Excel 用の `unmatched.csv`）に出力

終わったら、変更をコミットして push すれば公開ページに反映されます。

```powershell
git add data/zip_coords.json tools/report/unmatched.md
```

```powershell
git commit -m "郵便番号の対応表を更新"
```

```powershell
git push
```

### うまくいかないとき

- **ダウンロードに失敗する**：提供元のサイトのURLが変わった可能性があります。
  手動でダウンロードしたファイルを指定して実行できます。
  - 日本郵便：[郵便番号データダウンロード](https://www.post.japanpost.jp/zipcode/download.html) →「読み仮名データの促音・拗音を小書きで表記するもの」→ 全国一括（`ken_all.zip`）
  - 国土交通省：[位置参照情報ダウンロードサービス](https://nlftp.mlit.go.jp/isj/) → 都道府県ごとに「大字・町丁目レベル」の最新版（`11000-xx.0b.zip` など。末尾が **b** のもの）

  ```powershell
  python tools/build_zip_coords.py --ken-all C:\path\to\ken_all.zip --isj-dir C:\path\to\isj_folder
  ```

- **位置参照情報の版を指定したい**：`--isj-version 20.0b` のように指定できます。
- **照合できなかった番号を対応表に入れたくない**（市区町村の代表点に置かない）：`--no-city-fallback`
- **対象の都県を変えたい**：`--prefs 11,12,13,14,08`（都道府県コードをカンマ区切り）。
  変えた場合は、`index.html` の「位置不明」の説明文も合わせて直してください。

### 照合のしかた（参考）

- 市区町村コードが同じもの同士で、KEN_ALLの「町域名」と位置参照情報の「大字町丁目名」を照合します。
- 「丸の内」のように丁目のない町域名は、「丸の内一丁目〜三丁目」をまとめて平均します。
  町域名に「（１〜３丁目）」のような丁目の指定があれば、その丁目だけで平均します。
- ビル名付きの町域（例：「丸の内ＪＰタワー」）は、先頭が一致する町丁目（「丸の内」）を使います。
- 全角/半角、「ヶ/ケ」「ッ/ツ」「ヱ/エ」「ノ/の」、先頭の「大字」「字」の違いは同じものとして扱います。
- 1つの郵便番号に複数の町域・町丁目が当たる場合は、その座標を単純平均します。

### 2026年11月20日時点の作成結果

- 使用データ：郵便番号データ 2026年10月末更新分 ／ 位置参照情報 19.0b（令和7年）
- 郵便番号 13,035件（町丁目で決定 12,766件、市区町村の代表点 236件、町域名で照合できず 33件）
- 照合できなかった33件の一覧：[tools/report/unmatched.md](tools/report/unmatched.md)
  （位置参照情報の大字・町丁目データに同名の町丁目が載っていないもの。市区町村の代表点に置いています）

## ファイル構成

```
index.html                 画面（これ1枚で動きます）
data/zip_coords.json       郵便番号→座標の対応表（自動生成）
tools/build_zip_coords.py  対応表を作るスクリプト
tools/report/unmatched.md  照合できなかった郵便番号の一覧（自動生成）
```

`data/zip_coords.json` の中身は `"1900001": [緯度, 経度, "地名", "t"]` の形です。
最後の文字は `t`＝町丁目から算出、`c`＝市区町村の代表点 です。
